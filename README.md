# 提案查定ツール
Freelance Proposal Tool

フリーランスの提案内容を AI で自動評価し、案件適性を判定するツールです。

## 概要

フリーランスが企業からの案件（クラウドワークス、ランサーズなど）を受け取った時、以下を判定します：

- 📊 **案件適性ランク**（1～5）
- 💡 **プロ視点の分析**（現状分析 → 機会分析 → 実現筋道 → 懸念と対策）
- 🎯 **コンサルタント視点の洞察**
- 📋 **次のアクション**

そして、**案件IDを生成**して、フィードバック管理ツールと連携できます。

### 手順

**ステップ1：APIキー設定**
```
Claude API キー（sk-ant-...）を入力
↓
自動保存されます
```

**ステップ2：プロフィール入力**
```
【過去の職歴・経験】必須
例：事務職5年、接客業3年、データ入力経験あり

【得意なスキル】
例：Excel、Word、文章作成、データ入力

【苦手・避けたいこと】
例：電話対応が苦手、長時間の集中作業が難しい

【希望する働き方】
例：週10時間以内、時給1,000円以上、フルリモート

【生活上の制約・事情】
例：週3日は通院のため午前中不在、介護があるため急な対応が難しい
```

**ステップ3：案件情報を入力**
```
【仕事の詳細】必須
クラウドワークスなどから案件説明をコピペ

【応募条件】
例：アウトバウンド架電経験者・PC基本操作ができる方

【勤務条件】
例：平日9:00〜17:00・1日3時間から可・フルリモート

【契約形態・期間・報酬・稼働時間など】
詳細情報を入力
```

**ステップ4：査定実行**
```
「査定する」ボタン クリック
  ↓
AI が以下を自動生成：
- ランク（1～5）
- 4視点分析
- 洞察
- 次のアクション
```

**ステップ5：結果確認**
```
【ランク表示】
1: 簡単（完全マッチ）
2: 可能（十分対応可）
3: 普通（努力で対応）
4: 難しい（課題多い）
5: 無理（推奨しない）

【分析・評価】
4つの視点からの詳細分析

【洞察】
ビジネスコンサルタント視点のポイント

【次のアクション】
もし受けるなら最初に何をすべきか
```

## 🎯 ランク基準の詳細

### ランク1：簡単（経験・スキルが完全に合致）
- ✅ 経験・スキルが完全に合致
- ✅ 即戦力
- ✅ 生活制約との葛藤なし
- **判定**：ベストマッチ → **受けるべき**

### ランク2：可能（スキル面で多少不足だが対応可）
- ✅ スキル面で多少不足
- ✅ でも十分対応可能
- ✅ 制約内で実現可能な好機会
- **判定**：好機会 → **積極的に検討**

### ランク3：普通（努力で対応可、成長機会あり）
- ⚠️ 努力で対応可能
- ✅ 成長機会がある
- ⚠️ 一定のチャレンジあり
- **判定**：成長案件 → **状況による**

### ランク4：難しい（スキル・条件面で課題多い）
- ❌ スキル・条件面で課題が多い
- ❌ 実現には相応の工夫が必要
- ❌ 推奨度低い
- **判定**：要検討 → **慎重に判断**

### ランク5：無理（制約や経験不足で対応困難）
- ❌ 制約や経験不足で対応困難
- ❌ リスクが大きい
- ❌ 生活制約が合わない
- **判定**：推奨しない → **受けるべきではない**

## 💡 分析の4つの視点

### ①現状分析
ユーザーの経験・スキルと案件要件の具体的なマッチング度

```
例：
「営業経験5年はあるが、新規開拓営業は初。
既存顧客フォローはスキルマッチしているが...」
```

### ②機会分析
この案件を通じて何が学べ、キャリア・スキルにどう活きるか

```
例：
「業界知識が深まり、次の営業案件で活かせる。
人脈形成も可能」
```

### ③実現への筋道
生活上の制約や不得意な領域の中で、実現する具体的な道筋

```
例：
「週20時間の制約があるが、
集中する時間帯を限定することで対応可能」
```

### ④懸念と対策
正直に指摘すべき課題やリスク、およびそれに対する現実的な対策

```
例：
「新規開拓営業の経験不足が懸念。
対策として、既存営業ノウハウを活用し、
クライアント向け営業資料を事前準備」
```

## 💡 使用例

### ケース1：複数案件の比較
```
案件A を査定 → ランク3
案件B を査定 → ランク4
案件C を査定 → ランク2（ベスト）

→ ランク2の案件を選択
```

### ケース2：案件受け取り → 修整対応
```
提案查定ツール
  ↓ 案件評価 → 案件ID 生成
  ↓
フィードバック管理ツール
  ↓ 案件ID + 提案内容をペースト
  ↓ クライアント要望に対する修整案を生成
  ↓ PDF で提出
  ↓
案件ID で全工程が管理される
```

## 📞 よくある質問

### Q: 何度も同じ案件を査定できる？
**A:** はい。何度でも実行できます。内容を修正して再査定することも可能です。

### Q: プロフィール情報は安全？
**A:** LocalStorage に保存されるため、あなたのブラウザ内のみです。外部には送信されません。

### Q: 案件IDは何に使う？
**A:** フィードバック管理ツールでクライアント要望に対応するときに、提案書と紐付けるために使用します。
